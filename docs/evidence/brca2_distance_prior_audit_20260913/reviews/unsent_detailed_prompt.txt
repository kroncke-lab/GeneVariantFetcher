VERIFIED MODEL AND ARITHMETIC
BRCA2 has 6,656 canonical missense units. Its frozen prior is alpha=0.9074554792970309, beta=5.199318948641594, kappa=6.106774427938625, mu=0.1485981658574783. A unit with A affected, U unaffected, n=A+U has p=(alpha+A)/(kappa+n). Thus A=0,U=1 gives p=0.12768879728749818; A=1,U=0 gives p=0.2683996092233229. For A=0 this fixed prior needs integer U>=902 to give an own posterior <=0.001. The historical empirical prior fit uses y=A/n; w=1-1/(n+0.01); mu=sum(w*y)/sum(w); v=sum(w*(y-mu)^2)/M with M=number of units; kappa=mu*(1-mu)/v-1. These are the accepted historical formulas, not proposed new ones.

The proximity score D is a normalized, distance-weighted average of other variant units' p values, not pooled carrier counts. In each eligible context, K(d)=2/(1+exp(log(3)*d/3)), W=K/sum(K); normalize each context independently then average supported contexts equally. A donor uses its nearest eligible copy per context. Separate local coordinate frames never exchange Euclidean distances. Polymer donors must be in the same canonical IDR segment. Same-residue alternative variants can have d=0. Positive log-space normalization preserves a context even if every unnormalized K is tiny. There is no minimum absolute support requirement. Equal-variant weights mean a unit with many carriers is not automatically assigned more geometric weight than a singleton.
K(0)=1, K(3 Angstrom)=0.5, K(10)=0.05007419, K(20)=0.0013180604, K(30)=0.00003386960. The score has the exact decomposition D=mu*sum(W*kappa/(kappa+n)) + sum(W*A/(kappa+n)). The first term is an algebraic prior component, not necessarily positive causal inflation relative to raw-count neighborhoods. It is not a universal hard floor.
