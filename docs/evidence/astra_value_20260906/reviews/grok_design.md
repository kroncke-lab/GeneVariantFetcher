**The remaining $2.174 can decide only selective-Astra vs Grok+retry vs none. It cannot decide Astra on every paper.**

## 1. Flaw and repair

The proposed 6–8 paired Astra runs on “harder opened tasks” cannot decide regular-protocol value. Under conservative reservation (input + full output cap), 6–8 Astra calls do not fit unless sources or caps are silently shrunk into the same packetized, endpoint-shaped excerpts that already tied **168/168 numeric fields**. That would hide the original Astra deficit (six empty 32K-cap calls) and treat source-candidate derived counts as protocol value even though the unchanged validator previously accepted **one extra literal carrier and zero phenotype gains**. Opened, failure-enriched papers also cannot support a default-every-paper policy.

**Repair:** Freeze a small JSON output cap (not 32K), identical source, strict schema, generic instructions, and scoring **before any paid call**. Run **Grok 4.6 low on all 6–8 tasks**. Spend Astra only on a predeclared maximum of **2–3 unresolved tasks** (or until ~$2.00 reserved). Primary endpoint is unique **production-accepted** correct fields, not source-adjudicated extras. Do not promote a derived-evidence contract in this spend.

## 2. Minimal paired plan

Freeze, then lock outputs before scoring.

| Arm | When it runs | What it sees |
|---|---|---|
| Grok primary | All 6–8 tasks | Source + schema only |
| Grok retry (once) | Only if a frozen machine predicate fires | Same source + own invalid/incomplete output + “retry once under the same schema” |
| Astra low | Only tasks that still fail after Grok retry, cap 2–3 | Source + schema only; **no gold, no Grok output** |

**Retry is required iff** empty/truncated/invalid JSON, missing required keys, or self-truncated output. **Retry is forbidden** on the missing-section task if the model correctly leaves unknown as unknown; correct abstention is not “unresolved.” Triggering is a function of the model’s own payload, applied before any reference scoring. Astra never gets a cheap-model hint unless you are explicitly testing an adjudication arm (do not, in this envelope).

Include one of each: out-of-table genotype-linked relative; diagnosis vs symptom/timepoint; aggregate with no roster; missing section; one table-join roster. Stop constructing once those slots are filled. Do not add a second ceilinged roster.

## 3. Gate, penalty, stop

Weights frozen now: **+1** unique production-accepted correct field neither Grok nor retry accepted; **−3** extra accepted wrong carrier/affected/unaffected (or identity error that would ship); **0** for source-only derived counts the validator rejects; Astra empty/cap failure = miss, not a bye.

**Inclusion (selective only):** Astra unique production-accepted gain ≥ 1, harmful extra accepts = 0, and that gain occurs on a retry-unresolved task. Net score must be > 0.

**No inclusion:** unique production-accepted gain = 0; any extra harmful accept; or Astra’s only edge is citation-format/source-binding.

**Stop without further Astra** if: unresolved predicate never fires after Grok±retry; first Astra call adds a harmful accepted count; reserved spend hits ~$2.00; or the first three Grok tasks already match the frozen source reference on all scored fields (selection was not hard). This is an operational go/no-go on these tasks, not a population estimate.

## 4. What would justify each policy

**Default Astra:** not justifiable from this spend or prior evidence. That would need typical-stream production gains, not a hard opened slice, plus reliability against cap/empty failures, at 5× input / ~8× output. Unknown and untested here.

**Selective Astra:** only if, on predeclared unresolved tasks, Astra adds ≥1 unique **validator-accepted** correct field that Grok+retry miss, with no extra harmful accepts. Citation-bound rows (78/93 vs 71/93) are not enough.

**No Astra:** if production-accepted unique gain is 0 (the overlay pattern); Grok+retry matches Astra on accepted fields; Astra emits an extra accepted wrong count; or Astra again returns empty/capped. Then keep Grok 4.6 + one machine-triggered retry.

**Remains unknown:** unopened papers; human ceiling; average-paper value; whether changing the literal validator would unlock derived counts (a product change, not a model-inclusion result); Astra medium vs low on a fair pair; timeout root cause.
